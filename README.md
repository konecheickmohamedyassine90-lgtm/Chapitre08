# BookShelf Projet

## Description

Ce projet est une implémentation simple d’une bibliothèque de livres (`BookShelf`) en Java avec des tests unitaires utilisant JUnit 5.

Le projet permet :

* d’ajouter des livres dans une bibliothèque ;
* de récupérer la liste des livres ;
* de vérifier que la liste retournée est immutable ;
* de pratiquer les tests unitaires avec JUnit.
